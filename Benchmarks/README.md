# Попередні benchmark-сценарії

`LegacyCoreDataImportPerformanceTests.swift` збережено з попереднього iOS
проєкту як джерело сценаріїв і фабрики навантаження. Він не компілюється в
test target: частина сценаріїв очікує чотири великі JSON-файли з того проєкту.
Для звичайних перевірок використовуйте `swift test`; при відновленні benchmark
слід відокремити синтетичні сценарії від вимірювань реальних відповідей API.
